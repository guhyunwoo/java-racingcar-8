# java-racingcar-precourse

## 기능 구현 리스트

- [ ] 자동차 경주 기능
    - [x] 자동차 이름을 입력받는 메시지를 출력한다. (ex. 경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분))
    - [x] n대의 자동차를 입력을 받는다. (ex. 현우,지원,pobi)
    - [x] 입력된 문자열을 구분자 ','로 파싱한다.
    - [x] 경주 시도 횟수를 입력받는 메시지를 출력한다. (ex. 시도할 횟수는 몇 회인가요?)
    - [x] 경주 시도 횟수를 입력 받는다.
    - [x] 경주 시도 횟수만큼 랜덤 값을 돌린다.
    - [ ] 랜덤 값에서 전진 조건인 4 이상일 경우에 전진시킨다.
    - [ ] 매 경주 자동차의 이름과 전진 상황을 출력한다. (전진은 1회당 문자 '-' 한개로 표기한다.)
    - [ ] 최종 우승자를 출력한다. (ex. pobi,현우)

<hr />

#### 예외 - 공통
- [ ] 빈 값이 입력되었을 경우. (ex. 잘못된 입력입니다.)

#### 예외 - 자동차 이름 입력
- [ ] 자동차 이름이 5자를 초과할 경우 예외가 발생한다. (ex. 자동차 이름은 5자를 넘을 수 없습니다.)

#### 예외 - 경주 시도 횟수 입력
- [ ] 경주 시도 횟수가 0 이하일 경우 예외가 발생한다. (ex. 잘못된 입력입니다.)
- [ ] 경주 시도 횟수가 숫자가 아닌 경우 예외가 발생한다. (ex. 잘못된 입력입니다.)
